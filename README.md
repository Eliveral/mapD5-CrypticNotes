# MapD5 · Cryptic Notes

《第五人格》加页手记的 Windows 地图助手。S1 磷光症噩梦收录 15 套布局、45 个楼层。按地图键展开游戏地图时，助手按当前楼层匹配并叠加高清底图。负二和负三标出维修站，负三另标寰星房和炼金室。

## 安装

1. 从 [发布页](https://github.com/Eliveral/mapD5-CrypticNotes/releases/tag/v3.7.16-rc.1) 下载 `MapD5-Windows-x64.zip`，完整解压到一个文件夹，再双击 `MapD5.exe`。
2. 首次选择「安装 S1 地图」。程序自带当前地图索引，从注明的上游固定版本下载约 18 MiB 的高清底图，并逐张校验。装好后可以离线使用。
3. 回到游戏，按自己的地图键。默认是 Caps Lock，可在「检测设置」里改为 M 或 Tab，并调整底图不透明度。F9 隐藏或恢复覆盖，F10 停止检测。

## 更新程序

从 3.7.16 开始，助手启动后在后台检查本仓库的 GitHub Releases。点右上角版本或打开「程序更新」，有新版时点「一键更新并重启」。测试版跟踪测试版与正式版，正式版跟踪正式版。同系列优先用小补丁，其他受支持的版本用完整 Windows 包。下载或校验失败可重试；新程序启动失败会尝试恢复原版。个人地图库和快捷键保存在用户目录。

3.7.15 及更早版本首次升级，可下载本版完整包，或关闭助手后用 3.7.x 补丁替换 MapD5.exe。此后更新沿用同一启动位置。

发布新版本时，将 `s1_program_update.APP_TAG` 设为发布标签（例如 `v3.7.16-rc.1`），再构建 Windows 程序。只有在运行库与整个对应版本系列兼容时才发布 `MapD5-主.次.x-to-主.次.修订.zip`，其中包含 `MapD5.exe`。完整包名为 `MapD5-Windows-x64.zip`，根目录为 `MapD5/`。更新器使用 GitHub 返回的附件大小与 SHA-256。

## 更新地图

3.7.15 测试版支持负二、负三双向切层定位。负二与负三双向切换时，助手用上一层角色位置、两层通道的坐标和目标层上次的位置寻找对应房间。经当前墙边核对后，一个维修站房间就能显示，目标层位置和图号有冲突时继续核图。完整的普通房间也可按角色映射位置核对轮廓，部分普通墙角需要已有目标层参照。

3.7.14 测试版支持直接在负二按局部定位。开局直接到负二时，三间以上房间的固定墙角若能明显排除其他布局，先显示负二本层。整局锁定仍需多次确认，负三不会借用尚未锁定的编号。

3.7.13 测试版在地图锁定后，拖动和缩放只跟踪可见墙角，队友栏和右下角的固定图标从位置计算中排除。正常跟随优先于跨层推算，并按最新像素绘制一次。跟丢、出现矛盾或需要定期校验时仍可复核布局。

3.7.12 测试版：每局只在首次读到楼层时处理开局随机落点。之后拖动、缩放和正常换层沿用已确认布局，按当前墙线更新位置。旧覆盖挡住墙线时重取干净画面；明确的固定结构矛盾仍可纠正错图。同一游戏窗口开始下一局可点「新对局」。

3.7.11 测试版直接读取高亮楼层按钮的数字。首次或换层进入负二、从负二直接进入负三，都会根据当前落点重新核图。重新打开后若地图明显改变、只露出很少的房间，旧覆盖会先隐藏。多套布局胜过原图但彼此相似时继续等待；已展开的地图也可以用两个互不重叠的区域分别确认同一底图。图号相同时仍会按当前墙线校正位置及大小。

3.7.10 测试版会对随机传送后的负三画面独立核图。负二与负三仍可按已标定的通道衔接；负三出现明确反证时暂停旧覆盖，两次核对要包含新墙角，才能改用当前层的底图。回到负二时再核负二。负四尚无底图，助手会隐藏覆盖。

3.7.9 测试版改进缩到全览后的跟随。程序读取地图缩放滑块的变化，再通过画面中可核对的房间和墙线确定比例与位置。缩小后可以继续拖动、关图重开或放大。负一入口相似时仍只显示可确定的共通区域。 已锁定布局遇到不同的负二候选时先暂停覆盖，待负二复核通过再切换。重开时先核对当前位置，以减少先画旧位置再跳动的情况。

3.7.8 测试版在负二确认本局后预载对应负三。负三首次开图会在同一帧优先核对继承位置；游戏重新居中时，在这套负三内用已露出的房间和走廊重新对齐。

3.7.7 测试版在 15 套负三的高清单层、三层总览和游戏地图覆盖中标出「炼金室」。图鉴上带火焰图标的小长方形对应这个房间。已安装 3.7.x 的用户替换程序即可，无需重新下载地图。

3.7.6 测试版会定期用游戏里的固定墙线复核覆盖位置。整图平移偏差优先只校正位置，房间大小保持原比例。负一入口若属于多套布局，保留共通区域；负二独立比较 15 套，不会只因负一的编号沿用错图。

锁定后仍会复核负二。若多处固定结构明确支持另一套，会撤下旧图，在负二先显示重新定位的候选；其他楼层等复核完成。重复打开同一小块局部只计一次。三次充分核对后自动更正本局，只有一间随机隐藏房时不改判。

3.7.5 测试版会在后台用三个新采集的负二画面分别核对本局布局。每次都比对全部 15 套，要求多处固定房间和走廊支持同一张图。窗口会显示核对次数。三次一致后，本局只在锁定布局中定位；随机隐藏房、短暂关图、切楼层或切出游戏都不会换图。开始下一局时点主窗口的「新对局」。换到另一个游戏窗口也会重新确认。

3.7.4 测试版改进局部地图跟随。进入相邻楼层时，可用固定房间和走廊的局部折角定位；同层拖动或重新打开时，可从本局已见过的一小块房间继续对齐。已经露出的随机房间保留游戏画面。首次只露出从未定位的隐藏房时，助手会等可核对的墙线。测试版的实战覆盖范围仍在核对。

在「地图更新」选择「检查地图更新」。如已单独下载 `MapD5-S1-*.zip`，可选「导入地图包」。安装成功后，助手重新载入图库和识别器。下载或校验失败时，原图库继续可用。公开地图包包含标定数据与带校验值的高清图源，首次安装该包仍需连接图源。

用户设置、已安装版本及本机诊断图位于 `%LOCALAPPDATA%\CrypticNotesAssistantS1`。程序在本地匹配截图。更新请求发送到 GitHub 和公开图源，诊断截图保存在本机。

3.7.3 可以在「地图库 → 上下层对照」查看每套地图的负一 / 负二和负二 / 负三重叠图。橙色与蓝色分别表示两层，灰白表示共同轮廓。15 套均标出升降梯与维修站的对应位置。

切层时，助手沿用已确认的布局、比例和视角。视角变化时，它用上一层的通道位置和新层露出的墙边校准。比如，已确认角色在负二维修站附近，负三首次只露出相应墙角也可接上。位置有歧义时继续核对当前画面。地图开着时，一般刷新会保留当前覆盖，下一张定位完成后直接替换。已装 3.7.x 的用户可用发布页的小补丁更新。

公开包面向 S1 磷光症。厄运之女的原版入口见「检测设置」，使用原作者提供的模型和资源。当前版本已用保存的局内画面验证，短开地图、换层和各设备缩放下的实战体验仍欢迎反馈。

## 开发与地图维护

源码在 `game_map_identifier`。在 Windows x64 使用 Python 3.11 安装 `requirements.txt` 所列依赖。运行 `python game_map_identifier/run_s1.py`，首次可在「检查地图更新」安装地图。Windows 打包命令为 `python -m PyInstaller MapD5.spec`。在 `dist/MapD5` 旁的资源目录内保持标准目录结构，将当前地图索引命名为 `maps.zip` 放到 EXE 同目录即可生成与发布版相同的首次安装入口。

独立地图包及更新清单格式、发布顺序见 [地图维护](MAPS.md)。
